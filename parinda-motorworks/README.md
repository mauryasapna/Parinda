# Parinda Motorworks — Next.js Website

Premium adventure/off-road destination website concept based on the supplied Parinda Motorworks presentation.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Before client delivery

1. Replace `/public/images/placeholder.svg` with approved Parinda photography and update paths in `data/site.ts`.
2. Replace placeholder phone/email/location with real client details.
3. Add the final logo/favicon.
4. Connect booking/contact forms to the client's preferred backend/email service.
5. Review all wording with the client before publishing.

The included `PARINDA-MOTORWORKS-REFERENCE.pdf` is the original supplied design reference.
